# Project skills

| Skill | Purpose |
|---|---|
| `/typecheck` | Check Rust and TypeScript |
| `/sync-types` | Compare Rust structs with TypeScript interfaces |
| `/dev` | Run and monitor Tauri development |
| `/test-ai` | Inspect AI prompts and payloads |
| `/tdd` | Red-green-refactor workflow |
| `/record-demo` | Record an explicit Playwright demo |

Use only the skill relevant to the current task. Normal verification is the background-only command:

```bash
npm run test:harness
```

Browser automation and demo recording are opt-in, not part of the default harness.
